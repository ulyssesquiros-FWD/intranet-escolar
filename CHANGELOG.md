## Formato de futuras versiones

Las nuevas versiones se documentarán utilizando categorías como:

### Added

Nuevas funcionalidades.

### Changed

Cambios realizados sobre funcionalidades existentes.

### Fixed

Correcciones de errores.

### Removed

Funcionalidades eliminadas.

### Security

Cambios relacionados con seguridad y protección de datos.
